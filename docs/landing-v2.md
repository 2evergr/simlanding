# 온도더시 랜딩페이지 v2 구현

## 디자인 기준

회사 온도더시 → 브랜드 고래풀 → 시오콘부 → 문의 순으로 구성한다. 헤더에는 텍스트 워드마크만 제공한다. 헤더 메뉴와 첫 화면의 두 버튼은 없다. 시오콘부 영역에 영양성분·제품정보 버튼을 제공하며 기존 `product_detail.html`로 연결한다. CNAME은 변경하지 않는다.

색상은 오션 #087CB8, 스카이 #67CBE8, 페일 #EAF7FC, 흰색 #FFFFFF, 네이비 #12354A. 본문은 데스크톱 18px, 모바일 16px이며 최대 콘텐츠 폭은 1200px이다. 768px 미만은 단일 열이며 좌우 24px 여백을 둔다. 첫 화면 제목은 데스크톱 최대 64px, 모바일 38px, 360px 미만에서 34px로 조정한다. 제품 설명과 연락처를 이미지 시안처럼 작게 축소하지 않는다.

스크롤로 내용을 탐색한다. 키보드 사용자를 위한 포커스 시 표시되는 본문 바로가기, 회사 홈 링크, 전화·메일 링크를 제공한다. 회사 소개 영역은 화면에 고정된 이미지 위에 제목과 세 가지 항목을 겹쳐 놓고, 스크롤 위치에 따라 이미지와 강조 텍스트가 교차 전환되는 스크롤 스토리로 구성한다. 모션 감소 설정에서는 전환 효과를 끈다.

## 자산과 사실성

기존 img/ondo의 사진은 내장 image_gen으로 생성한 컨셉 이미지다. 실제 산지·시설·원재료 구매처를 증명하지 않으며 기존 제품 사진도 실제 촬영본이 아니다. 제품 사진에는 연출·활용 이미지 캡션을 표시한다. 각 이미지의 640px/1440px WebP 변형을 제공하며, 렌더링 시 srcset과 sizes로 크기를 선택하고 첫 화면 외에는 지연 로딩한다.

회사명과 브랜드명은 검색·확대가 가능한 텍스트다. 확인되지 않은 학력·경력·인증·효능·실적·주소는 추가하지 않았다. 기존 시안의 영문 장식 문구도 채택하지 않았다.

생성 원본은 Codex generated_images에 보관하며 웹이 사용하는 파일은 모두 저장소 안에 있다. 스크롤 스토리용 컨셉 이미지는 `img/ondo/story/`에 저장했으며 실제 시설·직원·포장 사진을 의미하지 않는다. 두 번째 이미지는 세척·준비 과정, 세 번째 이미지는 해조류를 종류별로 정돈한 장면으로 교체했다.

시오콘부 슬라이드의 네 장은 내장 image_gen으로 만든 연출 이미지다. 시오콘부와 참깨 주먹밥, 계란밥, 토마토·시소 무침, 양배추 무침을 표현한다. 검색한 실제 요리 사진은 구도와 음식 종류를 정하는 참고 자료로만 사용했고, 원본 사진이나 워터마크가 있는 미리보기는 사용하지 않았다. 이 이미지들은 실제 고래풀 제품이나 요리를 촬영한 사진이 아니며, 사이트에도 이를 명시한다.

## 운영 전 확인

현재 회사소개와 제품정보의 주소 표기가 서로 달라 새 랜딩페이지에는 주소를 싣지 않았다. 실제 제품 사진·확정 CI·회사정보를 확보하면 추후 갱신할 수 있다.

## 검증 기록

- `npm ci` 및 `npm run build:css` 성공. SCSS·CSS·소스맵을 함께 반영.
- 로컬 브라우저에서 320/390/768/1440px 폭 확인: 가로 넘침과 본문 잘림 없음.
- 1440px 화면의 200% 확대에 해당하는 720px 레이아웃 폭에서도 가로 넘침 없음. 브라우저 실제 배율 조작은 도구에서 지원되지 않아 동일 유효 너비로 리플로 검증.
- 이미지 네 장 모두 정상 로딩. 화면 밖 이미지의 lazy loading 확인.
- 키보드 본문 바로가기 → main 포커스 → 전화 → 이메일 순서와 초점 외곽선 확인.
- 헤더 메뉴·첫 화면 버튼·GSAP 스크립트가 없는지 구조 검사. 로컬 자산 경로 및 전화·메일 링크 검사 통과.
- 브라우저 콘솔 오류·경고 없음. product_detail.html, CNAME, package-lock.json은 기준 커밋과 동일.
- `git diff --check` 통과.
- 스크롤 스토리 스크립트 `node --check js/company-story.js` 통과.

## 시오콘부 이미지 슬라이드

네 장의 연출 이미지를 5초 간격으로 자동 전환한다. 화면에 보일 때만 재생하고 마우스를 올리거나 키보드로 조작할 때, 브라우저 탭이 숨겨졌을 때는 일시 정지한다. 모션 감소 설정에서는 자동 재생하지 않으며 이전·다음 버튼과 이미지 선택 버튼은 사용할 수 있다. JavaScript를 사용할 수 없어도 첫 이미지는 남는다. 제품의 영양성분·표기정보로 가는 버튼은 `product_detail.html`을 향한다.

기존 잠금 파일의 Sass 개발 의존성 immutable에서 npm audit high 1건(두 권고: GHSA-xvcm-6775-5m9r, GHSA-v56q-mh7h-f735)이 보고됐다. 이번 랜딩페이지는 해당 코드를 브라우저에 배포하지 않는다. 개발 의존성 갱신은 이 디자인 작업과 분리했으며 잠금 파일을 변경하지 않았다.

## 브라우저 피드백 반영

브랜드 소개의 고래 그래픽과 고래풀 로고 묶음을 삭제했다. 제품 소개의 50 g 용량 표기도 삭제했다. 설명 문장과 푸터의 브랜드명, 별도 제품 표기정보 페이지는 유지한다.
